# PetCare Mobile Application

PetCare is a mobile application developed using Flutter to help pet owners manage important information about their pets in a simple and user-friendly way.

This project was developed as part of a mobile application development assessment. The main focus of the current version is the implementation of the application's front-end based on a high-fidelity prototype designed in Figma.

## Main Features

### Login and Registration
Users can access a login interface or create a new account. Basic input validation has been implemented for the front-end demonstration.

### Pet Profile
Users can view their pet's information, including name, type, breed, gender, birthday and weight. Pet information can also be edited through the Edit Profile functionality.

### Pet Reminders
Users can view pet-care reminders for activities such as feeding, medication and vaccination. New reminders can be added and existing reminders can be deleted.

## Future Features

The following features were included in the prototype but are planned for future implementation:

- Vet appointment management
- Health records
- Database/cloud storage
- Push notifications
- Full user authentication

## Technologies Used

- Dart
- Android Studio

## Project Status

The current version demonstrates the main front-end functionalities of the PetCare application. Further development could include backend integration, persistent data storage and notification services.
